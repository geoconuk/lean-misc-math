# Recorded read-backs

One file per result, `<Area>/<Result>.md`, holding the blind read-back of its advertised
statements verbatim: the rendering an agent produced from the Lean alone, the model that
wrote it, the date, the commit the statements were taken at, and what the comparison against
the informal statement found. [`docs/READBACK.md`](../READBACK.md) says how a read-back is
produced and what goes in the file; the result's `## Provenance` section points here.

The three results published before this directory existed —
`Analysis/KolmogorovArnold`, `Geometry/SphereCoveringExponent` and
`Probability/PoissonTrialsFixedMean` — had read-backs, but their renderings were not kept;
what survives is the summary under each one's `## Provenance`. A rendering appears here for
one of them only if its statements are read back again.
